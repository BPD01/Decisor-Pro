Ferramenta de Análise Multicritério

Tome Decisões Inteligentes com Precisão

O Decisor Pro utiliza os métodos ELECTRE-I e PROMETHEE-I e II, uns dos métodos mais completos da análise multicritério, para ajudá-lo a encontrar a alternativa mais favorável entre diversas opções.

Por que usar o Decisor Pro?

Nossa ferramenta combina complexidade matemática com simplicidade de uso para resultados confiáveis

Análise Multicritério

Compare alternativas considerando múltiplos critérios simultaneamente, cada um com seu peso e importância relativa.

Método ELECTRE-I

Implementação fiel do consagrado método francês de sobreclassificação, amplamente utilizado em tomada de decisões complexas.

Método PROMETHEE-I e II

Implementação completa do método francês PROMETHEE-I e II para análise de fluxos de superação e ranking completo de alternativas.

Como Funciona a Análise

Processo simples em 6 passos para resultados precisos

1

Seleção do Método

Escolha entre ELECTRE-I ou PROMETHEE-I e II para conduzir sua análise multicritério.

2

Configuração

Defina as alternativas, critérios, pesos e a direção de preferência (maximizar ou minimizar) para cada critério.

3

Avaliação

Atribua o desempenho de cada alternativa em relação a todos os critérios estabelecidos.

4

Cálculo

O sistema processa automaticamente as matrizes de concordância e discordância ou fluxos de preferência.

5

Visualização

Gere grafos e matrizes para interpretar os resultados de forma clara.

6

Resultado

Obtenha um ranking claro das alternativas.

Método ELECTRE-I

Configuração Inicial

Forma de entrada dos dados

Use o modelo fornecido. Na linha Tipo, informe apenas MIN ou MAX.

Nomes das Alternativas

Configuração dos Critérios

Para cada critério, defina nome, peso (0-1) e se é para maximizar ou minimizar. A soma dos pesos deve ser aproximadamente 1.

Tabela de Avaliação das Alternativas

Preencha os valores de cada alternativa para cada critério. Valores maiores são melhores para critérios de maximização, valores menores são melhores para critérios de minimização.

Resultados da Análise ELECTRE-I

2 Matrizes de Concordância e Discordância

Matriz de Concordância (C)

C(l,k) = soma dos pesos onde alternativa l é pelo menos tão boa quanto k

Matriz de Discordância (D)

D(l,k) = maior diferença normalizada onde l é pior que k

3 Limiares de Corte
4 Matriz de Sobredominância (S)

S(l,k) = 1 se C(l,k) >= p e D(l,k) <= q

5 Grafo de Sobreclassificação

    Configuração Inicial

    Forma de entrada dos dados

    Use o modelo fornecido. Na linha Tipo, informe apenas MIN ou MAX.

    Nomes das Alternativas

    Configuração dos Critérios

    Para cada critério, defina nome, peso, direção (max/min) e a função de preferência com seus parâmetros. Os pesos serão normalizados automaticamente (soma = 1).
    Tipo 1 - Usual
    P(d)=0 se d≤0, 1 se d>0     Tipo 2 - U-shape
    P(d)=0 se d≤q, 1 se d>q     Tipo 3 - V-shape
    P(d)=d/p se 0<d<p, 1 se d≥p     Tipo 4 - Level
    P(d)=0 se d≤q, 0.5 se q<d≤p, 1 se d>p     Tipo 5 - Linear
    P(d)=(d-q)/(p-q) se q<d<p     Tipo 6 - Gaussiana
    P(d)=1-e^(-d²/2σ²)

    Tabela de Avaliação das Alternativas

    Preencha os valores de cada alternativa para cada critério.

    Resultados da Análise PROMETHEE-I e II

    1 Matriz de Decisão Original

    Valores originais inseridos pelo decisor (sem normalização)

    2 Matrizes de Diferenças por Critério dj(a,b)

    Maximização: d(a,b) = g(a) - g(b) | Minimização: d(a,b) = g(b) - g(a)

    3 Matrizes de Preferência Unicritério πj(a,b)

    Cada critério tem sua própria matriz de preferência, aplicando a função escolhida

    4 Matriz de Preferência Global π(a,b)

    Média ponderada das preferências unicritério

    5 Fluxos de Superação

    Φ⁺(a) = média da linha | Φ⁻(a) = média da coluna

    Fluxo Positivo (Φ⁺)

    Fluxo Negativo (Φ⁻)

    Fluxo Líquido (Φ)

    6 PROMETHEE-I - Pré-ordem Parcial

    a ≻ b se Φ⁺(a) > Φ⁺(b) e Φ⁻(a) < Φ⁻(b)

    PROMETHEE-II - Ranking Final

    Ordenado pelo Fluxo Líquido Φ(a) = Φ⁺(a) - Φ⁻(a)
